# Decisions — thematic ADRs

Accepted commitments of this project, one file per subject, ordered by number (akmon
`pipelines/design-flow.md` § Artifacts and § Decision blocks). A block carries a stable
`Decision-ID: ADR-<nnnn>/D<nn>`; a later change gets a new ID and a supersession link. No dates —
git history is the timeline. Open questions and implementation state live in the backlog
([TASKS.md](../TASKS.md)), not here.
