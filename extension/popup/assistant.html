Optimization methods
Random (default)
Selects random values for all parameters at once on every test.
Random improvement
Changes one random parameter to a random value from its whole range. A better result becomes the new state, and the next changes start from it.
Sequential improvement
Improves the best state already found, one parameter at a time: all values of the first parameter are checked, the best one is kept, then the next parameter is checked, and so on. It does not search the whole parameter space.
Annealing
Finds a good result in fewer steps. It starts from the best state and changes parameters to random values; a better result becomes the new state. As the tests go on, the spread of values narrows ("cools down") around the best values found: first it explores the whole space, at the end it refines the best state. From time to time it changes all parameters at once, so it does not get stuck in one area like the sequential method.
Brute force
Tests every combination of values in the parameter space.

More details in the repository description.

Automated use of TradingView may violate its rules and lead to an account ban. The extension does not bypass its protections but repeats UI actions: use it carefully, at your own risk.
